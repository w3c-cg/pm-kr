# A need that crosses groups

**Status:** an individual's input to the Procedural Memory Knowledge Representation Community Group, by Daniel Campos Ramos, 6 November 2026.
It is not a decision or a report of the group.
Comments and objections are welcome in this repository's issues.

## The question

Stereo video on the web touches media, immersive content, HTML or CSS, and colour.
I started in a Community Group, brought the problem to an Interest Group call, then to issues in the Media and Immersive Web groups ([the route](../talks/2026-10-27-tpac-mind-the-gaps/README.md#2-who-owns-a-need-that-crosses-groups)).
Each group answered for its own part, and the need as a whole had no owner.
Who triages a need that crosses groups and keeps it moving between them?

## The idea

Two small pieces of process, both already familiar at W3C.

1. **A path between groups through their chairs.**
   A Community Group chair sends a note to the chairs of the related groups, who approve it for their own lists, and a shared space lets those groups cooperate while each list stays focused.
   Working Groups already have horizontal review across accessibility, internationalization, privacy and security ([W3C document review guide](https://www.w3.org/Guide/documentreview/)); the question is whether Community Groups get a comparable route ([Community Group tools input, point 6](../talks/2026-10-28-tpac-cg-redesign/README.md#6-a-path-between-groups)).
2. **An owner for each step, named in the request.**
   The stereo migration path asks it plainly: the Media Working Group for reading and exposing the mark, the Immersive Web groups for author-made stereo, the CSS Working Group or HTML for handing the element to the compositor ([questions for the group](../talks/2026-10-13-w3c-me-ig/migration-path.md#questions-for-the-group)).
   A need written as steps with a candidate owner each is easier to route than a need written as one wish.

## Where it exists today

- The route itself: the Media and Entertainment Interest Group [minutes of 13 October 2026](https://www.w3.org/2026/10/13-me-minutes.html), where Chris Needham asked how it fits Apple's `<model>` proposal and whether it had been brought to the Immersive Web Working Group, and Kaz Ashimura suggested a TPAC breakout with input from Immersive Web.
- At the Mind the gaps breakout of 27 October 2026, "Which group should own stereo for the video element?" stayed unresolved ([minutes](https://www.w3.org/2026/10/27-mind-the-gaps-minutes.html)).
- The same shape at larger scale: the Web of Worlds [group map](web-of-worlds-task-force.md), one row per area with the W3C groups that hold it and the bodies outside W3C.
