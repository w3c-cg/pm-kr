# PM-KR skills

Instructions that a person can follow directly, and that an AI partner can follow to help that person.
Each skill is a folder with a `SKILL.md` (a short working recipe first, details after, every fact dated and linked).
They are individual contributions offered to the group, not outputs of the group.

| Your task | Read |
| --- | --- |
| Use the PM-KR notebook in Gemini Notebook (formerly NotebookLM): sources, settings, Slide Deck, Video Overview and the other Studio features, and checking what it makes | [notebooklm](notebooklm/SKILL.md) |

To use a skill with an assistant that reads skill folders, link or copy the folder into that assistant's skills folder (for example `~/.claude/skills/` for Claude Code or `~/.agents/skills/` for Codex).
